// what we build

Real projects, not slideware

Everything here is something we're actually working on. Some of it runs today, some is in progress, some is research. We'll tell you which is which.

research · simulation running neuro-AI · reservoir computing · robotics

A fly brain driving a real body

Our own research. We run the full fruit-fly connectome (MaleCNS v1.0, about 166,700 neurons, nothing trained) in simulation, wired to a physics body. It already reacts to what it sees and hears and moves that body, for example running from looming motion. Next we want to use it as a reservoir for reservoir computing, then move it onto hardware: real sensor input and a physical body driven by servo motors.

Connectome · reservoir computing · MuJoCo · FlyGym · servos
working prototype web · platform

Lint Contest Platform

A coding practice and contest platform — problems, a sandboxed code runner, contests and a leaderboard, with student, faculty and admin roles. It works, but it still breaks under load because of a database connection bug we're fixing, so it isn't public yet.

Next.js · PostgreSQL · Redis · Docker
in progress security · ed-tech

SecureCode

A secure-coding assessment platform (built for Smart India Hackathon 2026). The plan is to use AI to review student code for vulnerabilities, explain the fix, and help grade — inside a locked-down exam environment.

Assessment · proctoring · AI review
in progress hardware · firmware RE

Router reverse engineering

Reverse-engineering a proprietary router (Beetel 777VR1) with no datasheet — UART console, SPI flash dumps, Ghidra. We've mapped its firmware's LED control surface and are now tracing it down to the raw GPIO registers.

UART · SPI · binwalk · Ghidra · MIPS
research AI · RAG

Campus help-desk

A question-answering assistant for college departments: pull scattered department information into one place and answer student queries over it with a retrieval pipeline. Exploring it as a product for colleges.

RAG · retrieval · LLM

// how it works

Learn on real work. Get paid when it's paid.

Lint runs as a studio, not a course. You join, you work on live projects, and you grow into the paid work as it comes in.

01

Learn

We teach hands-on skills — firmware RE, web security, building real apps.

02

Do

You get practical tasks matched to your level, with honest feedback.

03

Get certified

Finish your tasks and get a certificate for your college record.

04

Get called in

When paid client work lands, the members who've shown the most get the work — and get paid for it.

▸ straight talk

We're at the start. We're still learning, and the honest way we learn is by breaking and fixing our own systems first before we touch anyone else's.

We're not a security firm, and we don't pretend to be one. Everything we test is our own hardware, or a system we have written permission to test.
